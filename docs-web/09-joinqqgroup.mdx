# 【学习交流】加入 QQ 交流群

您可以加入QQ交流群/频道交流简幻欢相关问题，需要**绑定**才可以进群/发言，违反群规可能会被封禁，请遵守规则。

## 绑定教程

+ 打开[简幻欢官网→控制台](https://simpfun.cn/console)，选择"其它"页面。
+ 在"绑定QQ号"处填写你的QQ号后，点击右边的"保存"图标即可。
