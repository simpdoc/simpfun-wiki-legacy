# 【实例管理】如何有效减少流量消耗

:::warning[您可能在浪费您的流量！]

你可能有一些疑惑，为什么您的流量消耗速度过快？这可能是你使用一些增加发包量的内容，本文档将提供节约流量消耗的方法。

:::

:::info[信息]
在此之前，了解BGP及其市场价！

+ 什么是BGP？

简单来讲，BGP是将国内三大运营商融合在一起的线路。其优点是会自动选择最优的运营商线路，实现更低延迟。

+ 为什么选择BGP？

在日常生活中，可能遇到访问某个网站速度极慢的情况，由于国内网络环境比较复杂，如电信单线，只有电信用户访问速度快，其他运营商的访问速度就没有那么好。那么BGP的优势就会体现出来——保证全国使用不同运营商用户的流畅访问！

+ BGP的市场价格？

虽然简幻欢长期提供不限速且不限流量，且为优质BGP线路的网络，但由于成本问题，终究选择了限流。那么，BGP的价格究竟如何？

## Minecraft-JE
### 修改 `server.properties`
+ **network-compression-threshold （网络压缩阈值）**

默认：`256`

推荐：`256`(一般无需修改。该参数表示超过指定字节数的数据包才会进行压缩。设置过低可能导致大量小包也被压缩，压缩收益有限，甚至可能增加 CPU 开销或使部分小包体积变大；设置过高则可能减少压缩带来的流量节省。若为整合包服务器，建议先保持默认值，确认运行稳定后再根据实际情况调整。）

+ **view-distance （视距）**

> 不同视距对服务器的性能消耗不同，进而影响流量消耗，同时也影响玩家视野。
>
> 若无特殊需求，推荐适当降低视距，在不太影响玩家体验的前提下节约性能和流量。
>

默认：`10`

推荐：`4-8`

+ **simulation-distance (模拟距离，1.18+)**

> 模拟距离控制玩家周围区块参与游戏逻辑模拟的范围，例如实体活动、方块随机刻、红石、作物生长等。它主要影响服务器计算压力，以及这些动态变化需要同步给客户端的数据量。
>
> 需要注意，`simulation-distance` 不等同于玩家可见范围。玩家能接收和看到多少区块主要由 `view-distance` 控制；`simulation-distance` 只是决定其中有多少区块会进行较完整的游戏逻辑模拟。
>
> 为了降低性能和流量消耗，通常建议将 `simulation-distance` 设置为不高于 `view-distance`。多数生存服可设置为 `4-6`，小型服务器或对实体/红石活动范围要求较高时可适当提高。
>

默认：`10`

推荐：`4-6`

### 避免跑图行为
> 跑图行为会大幅增加流量消耗，也会大量占用CPU性能。
>
> 若您仍需跑图，可使用Chunky预先加载区块，完成预加载后将一定程度上避免因跑图导致的卡顿问题，且支持绝大部分服务端。然而Chunky会一定程度上增加存储占用，请根据实际情况合理使用。
>
> 下载链接： [Chunky - Minecraft Plugin](https://modrinth.com/plugin/chunky)
>
> 使用教程：[预生成区块 (Chunky) - MC百科|最大的Minecraft中文MOD百科](https://www.mcmod.cn/class/6239.html)
>

### 避免使用导致大量发包的内容
> 以下插件/mod会导致流量快速消耗：
>
> + Allmusic 等点歌类mod/插件等。如果音频数据由服务器转发，可能会明显增加服务器流量；如果客户端直接访问外部音源，则通常主要消耗玩家与第三方服务的流量。
> + 部分播放外链视频等mod/插件。若资源通过服务器代理或转发，会增加实例流量；若客户端直连外部链接，则不计入实例流量。
> + 以 [Simple Voice Chat](https://www.mcmod.cn/class/3693.html) 为代表的游戏内提供语音聊天的插件/mod。在线人数越多、发言越频繁，流量消耗越明显。
> + 部分计分板插件，会向玩家发生更多数据包，可通过降低频刷新率等方式进行优化
> + 部分自定义TAB插件，会向玩家发送更多数据包，可通过修改其配置，降低频率，进行优化
>

## Minecraft-BE
### 修改 `server.properties`
+ **view-distance （视距）**

> 不同视距对服务器的性能消耗不同，进而影响流量消耗，同时也影响玩家视野。
>
> 若无特殊需求，推荐适当降低视距，在不太影响玩家体验的前提下节约性能和流量。
>

默认：`32`

推荐：`8-10`

+ **tick-distance (停止加载区块的距离)**

> 当玩家远离某个区块的距离超过设定值后，该区块会停止加载。较高的值可能会影响服务器性能。
>

默认：`4`

范围： `4-12`

推荐：`4`

### 避免不必要的附加包提供
> BDS提供了进服时自动下载附加包的功能，这虽然大大方便了玩家，但也可能导致部分玩家无法流畅游玩游戏，并且过大的附加包也会加剧流量消耗。因此只需让玩家自动下载必要的附加包，其余附加包通过其余渠道发布，让玩家自行选择安装的方式才是最优解。
