# 检查文件占用大小

:::info[信息]
您是否遇到以下问题：

+ 简幻欢磁盘占用更新不及时，无法确定占用？
+ 因占用过大无法开服，但排查不出？

:::

**本文档将教你如何排查！**

****

### **修改启动参数**
**在启动脚本**`**start.sh**`**内添加一个**`export PATH="$PATH:你需要的程序目录"`

:::warning[警告]
⚠注意！

这个脚本必须置于主启动命令前（一般为最后一行命令），否则主启动命令使用环境变量时将可能出现问题。

:::

![说明图片](/img/pages/web/check-the-file-size-1.png)

### **启动服务器，使用命令排查**

#### 检查总占用：
```bash
du -sh /home/container/.
```

![说明图片](/img/pages/web/check-the-file-size-2.png)

#### 检查当前目录（默认为/home/container)下每个文件夹/文件占用：
```bash
du -sh */
```

![说明图片](/img/pages/web/check-the-file-size-3.png)

#### 检查其它目录下每个文件夹/文件占用：
```bash
du -sh ./路径/*
```

![以./logs路径为例](/img/pages/web/check-the-file-size-4.png)

#### 文件夹/文件由大到小，排序展示：
```bash
du -sh ./路径/* | sort -rh
```

![以默认路径为例](/img/pages/web/check-the-file-size-5.png)

#### 有时文件夹下内容过多，简幻欢不会显示，可做额外限制，只展示其中几个：
```bash
du -sh * | sort -rh | head -展示数量
```

![以mods路径为例，只展示占用大小前五的文件/文件夹](/img/pages/web/check-the-file-size-6.png)

### 检查完毕后，将第一步中的修改内容删除或注释！

:::info[信息]
如需了解更多相关命令，可前往搜索引擎查阅更多教程！

:::
