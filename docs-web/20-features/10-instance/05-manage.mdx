# 管理

:::info[信息]
管理页包含了 `当前实例信息` ， `实例变配` ， `实例端口` ，`**SFTP文件管理服务器**`，`**实例管理**`五个功能。
:::

## 当前实例信息

这里显示着当前实例的详细信息，包括 `当前镜像类型`，`磁盘占用` ，`当前实例类型`等。

此处也会显示流量机制与自动补充操作，具体请点击 `当前实例信息` 标题右侧的 `？` 按钮。

如您在使用简幻欢遇到 `简幻欢` 功能异常的问题，可携带您的故障排错ID，前往  [问题答疑QQ群 ](https://qm.qq.com/q/GKWYB1zVCg)，在遵守相关规则的前提下寻求帮助。

![说明图片](/img/pages/web/manage-1.png)

## 技术支持（仅第三方镜像）

若你在使用第三方镜像遇到问题后，可先从实例->管理页，在技术支持处找到开发者QQ或技术交流群，与第三方镜像的开发者沟通。

请注意，该技术支持仅支持在第三方镜像中使用，且第三方镜像提供方为第三方开发者，简幻欢不负责镜像相关问题，由开发者承担。在技术支持的过程中开发者可能会向您收取相应费用，该费用与简幻欢无关。

![说明图片](/img/pages/web/manage-2.png)

## 实例变配

简幻欢提供了多种规格方案，且您可随时在资源节点充足的情况下自由变配。在变配前，务必查看变配规则和命名规则。

![说明图片](/img/pages/web/manage-3.png)

## 实例端口

您可在此处设置或新建端口。为避免滥用，仅对必要稳定用户提供增加端口功能。新建端口一次性收取一定数量积分，且每个实例存在端口上限。

:::danger[注意]
请注意：我们不支持搭建代理类应用，包括但不限于 FRP
一经发现，将会按照服务条款处理！
:::

![说明图片](/img/pages/web/manage-4.png)


## SFTP文件管理服务器

SFTP文件管理功能可以让您很方便的使用第三方客户端进行大批量文件上传/下载。您也可以点击密码右侧的图标刷新一个随机密码。

SFTP使用教程： [SFTP 连接指南](/web/advanced/sftp)

![说明图片](/img/pages/web/manage-5.png)


## 钻石补贴

您可以使用`钻石`兑换实例补贴，降低实例的积分消耗

补贴只针对一种实例类型(例如 B-.I.M+.L )的续期，变配到其它类型将视为放弃补贴

每次兑换补贴周期为固定**14**天，消耗 这里 显示的钻石数量

兑换相同的补贴将会自动叠加时长，但最长不能超过**28**天

补贴将根据节点负载情况动态调整，我们不保证新兑换补贴所需的钻石不变，也不保证您能够在未来的某个时间仍可兑换该补贴

![说明图片](/img/pages/web/manage-6.png)

## 实例管理

在实例管理处，您可选择销毁您的实例。

:::danger[危险警告]
请注意，这意味着**当前实例所有计算资源、数据全部放弃，且个过程是不可逆的**！
:::
