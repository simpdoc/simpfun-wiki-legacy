# 备份与还原

:::warning[镜像管理与回档管理的区别]
镜像管理：主动创建镜像将消耗一定积分，保留180天，实例被销毁时，将创建一个长达60天的镜像，适合长期冷备份存储数据。    
回档管理：简幻欢将自动创建回档点，可选择一个回档点进行回档，适合误操作，遭到破坏时回档使用。
:::

## 镜像管理

### 新建镜像备份

使用备份首先要创建一个备份，这个备份包含你创建备份时所有的服务器数据。

1. 进入实例
2. 点击备份
3. 点击镜像管理右上角的新建按钮

:::info[信息]
手动创建的镜像将保留180天，约半年左右，请务必记好到期时间！
:::

![说明图片](/img/pages/web/backup-1.png)

1. 输入一个**唯一**的标识，例如时间等，点击创建，支付 30 积分即可

![说明图片](/img/pages/web/backup-2.png)

### 还原镜像

当您需要将您的服务器还原至备份时的状态时，就需要进行还原。

:::danger[危险]
还原镜像将会删除现在服务器的所有文件，并还原至备份时的状态，   
且整个过程**不可逆**，**无法**为您进行**数据还原**，   
**因此造成的任何损失不进行赔偿。**
:::

1. 进入实例
2. 点击备份
3. 点击镜像管理中您想要还原到的备份
4. 点击右下角的还原按钮
5. 再次点击还原即可。

![说明图片](/img/pages/web/backup-3.png)

### 下载备份

1. 选中需要下载的镜像
2. 点击下载按钮
3. 生成链接后，点击下载

![说明图片](/img/pages/web/backup-4.png)

## 回档管理

回档能将服务器文件还原至历史某个时间点。

当出现操作错误或业务出现故障时，可以使用该功能。   
请注意使用该功能时将会**覆盖现有的所有文件**！   
**回档只能找回已写入磁盘的数据（如MCJE中未保存的存档不会被找回）**   
此功能不消耗积分。

![说明图片](/img/pages/web/backup-5.png)
