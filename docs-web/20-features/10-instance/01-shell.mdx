# 终端

:::info[实例终端 能干些什么？]
在 实例终端 中，您可以对 实例 发出指令   
如 `开机` `关机` `重启` `强制关机` 这四种自带指令   
您也可以在 **命令框** 输入您想要执行的 **自定义命令** 并回车执行  
:::

## 进入实例终端

在 `实例` 页面中，点击您想要管理的 `实例`，即可进入控制台！
