# 文件

:::danger[危险]
🔥危险！

请勿删除文件中的start.sh（无论何种方式），否则导致无法正常启动！

如误删，请在根目录重新创建start.sh文件并使用工具箱中的功能修复，并查阅 [启动参数](https://www.yuque.com/simpfun/sfe/startup) 或 [【额外内容】默认的启动脚本](/web/features/default_start)

:::

## 2.压缩/解压缩
:::danger[危险]
有的时候可能由于压缩格式，压缩算法，压缩包损坏等问题无法解压缩文件，您只能通过**如何使用 SFTP 管理文件**教程以使用SFTP传输文件夹。

:::

### 压缩
1. 进入实例，点击文件
2. 勾选需要压缩的文件/文件夹，支持多选
3. PC端可右键后点击压缩，手机端可通过右下角悬浮按钮点击后，选择压缩。

![说明图片](/img/pages/web/fileoperations-4.png)

等待任务执行完成后，回到文件页面，在服务器根目录下找到类似compressed20240426165745.zip的压缩文件，如下图所示：

![说明图片](/img/pages/web/fileoperations-5.png)

compressed后的数字即代表文件完成压缩时的时间(精确到秒)。

### 解压缩
1. 进入实例，点击`文件`
2. 勾选需要解压的压缩包
3. PC端可右键后点击解压缩，手机端可通过右下角悬浮按钮点击后，选择解压缩。

![说明图片](/img/pages/web/fileoperations-6.png)

### 进阶操作：使用面板命令行进行压缩/解压缩
[请移步这篇文档查看](/web/advanced/zip)

当然，您也可以使用一些支持修改权限的SFTP软件进行更进一步的权限修改！

:::

## 4.文件下载
:::warning[警告]
⚠注意！

不支持文件夹下载，也不支持超大文件下载。如需直接下载文件夹，可使用SFTP管理文件。（推荐关闭服务器后，将所有需要下载的文件压缩后再下载，以提高下载速度！)

:::

+ 进入实例，点击文件
+ 点击需要下载的文件
1. PC端可右键后点击下载文件，手机端可通过右下角悬浮按钮点击后，选择下载文件。

![说明图片](/img/pages/web/fileoperations-8.png)

:::warning[警告]
⚠ **提示**

如果浏览器无法创建下载任务或下载失败，请尝试更换浏览器！

推荐的浏览器：

PC端：[Chrome](https://www.google.cn/chrome/)，[Edge](https://www.microsoft.com/zh-cn/edge/download)，[Supermium](https://win32subsystem.live/supermium/)，[FireFox](https://www.firefox.com.cn/)

安卓端(前往手机应用商店即可下载)：[Edge](https://learn.microsoft.com/zh-cn/deployedge/microsoft-edge-install-mobile-china)，[Chrome](https://www.techspot.com/downloads/5818-google-chrome-for-android.html)

:::

## 5.权限和文件名乱码修复工具
### 在服务器运维时，文件权限及文件乱码一直是一个老生常谈的话题。在简幻欢中，提供了这样的工具。
#### 您只需：
+ 点击网页右下角的 `...`
+ 点击 `工具箱`
+ 点击 `解决权限和文件名乱码问题`
+ 点击 `执行`
+ 等待执行成功！
