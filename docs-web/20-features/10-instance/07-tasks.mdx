# 任务

## 任务队列

您可在此处查看您的操作历史，包括重装，压缩/解压缩等。在任务执行期间，您无法进行对该实例的任何操作。

关于任务队列机制可见[【账号管理】您需要注意的机制](/web/mechanism) 。

若对队列存在疑问（等待时间过长等），您可以加入QQ群：465468467 反馈，简幻欢将尽快为您解决！

![说明图片](/img/pages/web/tasks-1.png)

## 计划任务

计划任务可在特定时间执行命令（包括重启、关机、开机等）

:::info[注意]
关机、重启操作存在超时处理机制，即在一定时间内未执行成功，将强制关闭实例。   
建议关机与开机的时间间隔大于一分钟，保证顺利执行   
若要执行命令你无需添加/，即`stop`而不是`/stop`   
若有任务的实例变配那么已有的计划任务将会丢失
:::
