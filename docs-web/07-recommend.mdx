# 【账号管理】如何推荐

## 推荐的好处？
+ **让更多人知道简幻欢！**
+ **您可以获得更多积分！**
+ **不受签到机制限制，让他人成为您的无限造分****🐔****！**

---

## 如何推荐？
1.进入[简幻欢](https://simpfun.cn/)

2.进入控制台后点击推荐，可以看到：

+ 您推荐了多少人进行注册（注册人数）
+ 您推荐了多少人完成认证
+ 他们为您赚取的积分
+ 您的推荐码

:::danger[危险]
获取到的积分和钻石可能随时发生改变，请以官网为准。

:::

![说明图片](/img/pages/web/recommend-1.png)

将您的推荐码发送给好友，让他们在注册时填写您的推荐码即可。

## 小窍门：他人如何成为您的造分🐔？
+ **在哔哩哔哩等平台发布教程，实况等相关视频并附带您的推荐码 **
+ **推荐给您的好友使用**

****

## 限制
**1.您不得利用系统漏洞或使用小号获得不正当收益
****2.您不得将推荐码以任何形式（群名片，发言，私聊等）在简幻欢官方交流群内发送
****3.您不得以非正当方式（刷屏等）方式进行推荐
****违规将移出交流群，扣除推荐积分，严重者封号处理。**
