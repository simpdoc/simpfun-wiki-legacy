## 计划任务
### 计划任务可在特定时间执行命令（包括重启、关机、开机等）
:::info
💡注意

关机、重启操作存在超时处理机制，即在一定时间内未执行成功，将强制关闭实例。

建议关机与开机的时间间隔大于一分钟，保证顺利执行

若要执行命令你无需添加/，即`stop`而不是`/stop`

若有任务的实例变配那么已有的计划任务将会丢失

:::
