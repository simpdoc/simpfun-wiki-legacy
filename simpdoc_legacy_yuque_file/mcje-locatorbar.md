<font style="color:rgb(28, 30, 33);">定位栏是JE1.21.6/BE1.21.90后加入的一种显示其他玩家大致方位的功能，但是在某些服务器中可能并不需要开启这个功能。</font>

## <font style="color:rgb(28, 30, 33);">使用命令</font>
<font style="color:rgb(28, 30, 33);">打开服务器控制台>终端</font>

![](https://cdn.nlark.com/yuque/0/2024/png/32774263/1718170782648-7376423c-ade9-4f17-88b6-3cf5e2659c0b.png)

<font style="color:rgb(28, 30, 33);">输入以下命令(可直接复制，游戏内使用</font><font style="color:rgb(28, 30, 33);">ctrl+v</font><font style="color:rgb(28, 30, 33);">粘贴，控制台输入请去掉斜杠)：</font>

```plain
/gamerule locatorBar false
```

```plain
/gamerule locator_bar false
```

需要打开定位栏就把命令中的`false`替换成`true`即可。
