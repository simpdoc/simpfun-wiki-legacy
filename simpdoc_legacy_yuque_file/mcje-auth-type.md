> ## <font style="background-color:#81DFE4;">本文将为您讲解MCJE服务器中不同的登录方式，以便您更好保护您的服务器。</font>



:::warning
**⚠****严重误区！**

+ 有些人认为不公开自己的地址不会被入侵，无需额外的安全措施。这是严重的思维误区！在简幻欢中，即使不公开您的服务器地址，但由于公网IP的特性，也会因为其他各种原因可能导致被发现，入侵（如扫端，大规模发包卡服等）。因此，推荐您最好使用 `白名单+任意一种带验证的登录方式` 保护您的服务器，以免造成不必要的损失。

:::

## 1.不同登录方式区别
### 一表流（不添加任何额外插件，mod等情况下）：
| 登录方式 | 安全性 | 门槛 | 维护难度 |
| :---: | :---: | :---: | :---: |
| 离线登录 | 极低（无任何安全措施） | 极低（支持离线登录的三方启动器都可） | 较高（需自行添加额外的安全措施） |
| 正版登录 | 较高（依赖微软账号） | 较高（需要购买Minecraft正版） | 低（依赖微软） |
| 外置登录（通常为皮肤站） | 较高（依赖皮肤站） | 中（视皮肤站网站策略而定） | 较低（依赖皮肤站） |




## 不同登录方式详解，解决方案，注意事项
### 离线登录
> 离线登录是这三个登录方式中，最不安全的一个，因此需要额外的安全措施。
>

:::danger
⚠ 开启白名单并非意味着离线登录是安全的！

有不少人认为，在离线登录的情况下开启白名单就可以高枕无忧，实际上这是一个严重的误区。

由于离线登录的特点，一些三方启动器提供了自定义uuid的选项（如hmcl），而玩家在线的uuid也是可以通过查询工具等方式获取到的。你就算自定义 uuid 服务器默认由游戏 id 重新生成。简幻欢的 ip 已被加入毁服之选，24h 持续扫描在线玩家

意味着入侵者可以通过以上手段直接登录您的账号，造成严重后果！

:::

#### 解决方案
| 服务端类型 | 解决方案 |
| --- | --- |
| spigot，paper，leaves等基于bukkit api的插件服务端 | 使用[AuthMe](https://www.minebbs.com/resources/authmerereloaded-authme-folia.7734/) 等登录插件，可点击按钮查看详情。必要时可配合白名单插件（如 SimpleWhitelist），实现更好的防护 |
| Forge | 使用 [简单登录](https://www.mcmod.cn/class/1557.html) ，[新星登录](https://www.mcmod.cn/class/14385.html) 等登录mod，可点击按钮查看详情。必要时可配合白名单mod（如 SimpleWhitelist），实现更好的防护，一般来说你有强制客户端的 mod 也进不来 |
| Fabric | 使用 [EasyAuth](https://www.mcmod.cn/class/6241.html) 等登录mod，可点击按钮查看详情。必要时可配合白名单mod（如 SimpleWhitelist），实现更好的防护 |
| catserver，archlight等混合端，或信雅互联mod等混合方案 | 根据实际支持的服务端类型，选择上服务端类型的一个（只能选择其中一个，不可多选，以免造成不必要的麻烦） |


#### 注意事项
##### 对于spigot，paper，leaves等基于bukkit api的服务端：
> + 注意插件的配置，多阅读其中的使用文档，以免造成诸如在地狱传送门无法登录等不必要的麻烦。
> + 部分插件可能提供类似登录缓存的功能（如一段时间内免验证），这将降低账号的安全性，不推荐开启。
> + 大部分插件默认使用`SQLite`的方式存储您的登录数据，在一些场景下可能会数据损坏，推荐定期备份插件或整个服务端。
> + 如有需求，可使用插件的邮箱绑定功能（如支持），实现找回密码的功能。
> + 部分插件可能不支持诸如Folia的服务端，请注意。
>



##### 对于Forge，Fabric的mod服务端：
> + 请注意mod的使用环境，是否需要客户端和服务端同时安装，可通过 [MC百科](https://www.mcmod.cn/) 查询mod的运行环境。
> + 不同登录mod的安全验证方式不同，如用 [简单登录](https://www.mcmod.cn/class/1557.html) 需要客户端和服务端同时安装，但可以傻瓜式配置； [EasyAuth](https://www.mcmod.cn/class/6241.html) 仅需服务端安装即可，但需要玩家进入服务器后进行注册和登录操作，请根据实际需求选择不同的mod
>







### 正版登录
:::info
正版登录虽然提高了安全性，但由于微软服务的特点，使登录变得不稳定，可能遇到：

+ 正版账号提示未建立档案等
+ 验证服务器宕机

...

:::



#### 解决方案
##### 客户端无法正版登录
> + 使用加速器登录正版
> + 前往官网，检查是否建立档案
> + 尝试登录一遍 [Minecraft官网](https://www.minecraft.net/zh-hans) 后，再启动客户端
>

##### 客户端进入服务器时提示<font style="color:rgb(51, 51, 51);">身份验证服务器宕机</font>
> + 等，或多尝试几次
> + 通过修改host等的方式，保证能够连接到微软服务器（有一定难度，可能导致网络问题，不推荐）
> + 使用 [Always Online ](https://www.mcmod.cn/class/14514.html)等mod，在<font style="color:rgb(51, 51, 51);">身份验证服务器宕机时仍可进入服务器</font>
>









### 外置登录（皮肤站）
:::info
外置登录高度依赖皮肤站及其网站的策略。

如何使用外置登录？[使用第三方验证服务器登录](https://www.yuque.com/simpfox/simpdoc/authlib-injector)

:::

#### 解决方案
##### 无法登录（包括服务器
> + 可能是因为网站策略导致被临时屏蔽，尝试使用其它皮肤站或放弃使用外置登录
> + 检查本地或服务器是否能够正常访问皮肤站，如皮肤站无法访问应换一个皮肤站
>



#### 注意事项
> + 如遇到登录失败等问题，应先查看本文档，再查看皮肤站公告，或向皮肤站管理员，社区等寻求帮助，而不是向简幻欢寻求帮助，简幻欢并不提供皮肤站支持。
> + 客户端使用外置登录并不意味着服务端也使用了外置登录，服务端使用外置登录的方法：[使用第三方验证服务器登录](https://www.yuque.com/simpfox/simpdoc/authlib-injector)
> + 推荐使用源服务器在中国大陆的皮肤站，以免导致部分玩家无法使用外置登录的情况。可使用 [阿里云网站运维检测平台](https://boce.aliyun.com/detect/ping) 等网站检查皮肤站是否在中国大陆。
> + 部分皮肤站可能允许一个账号开多个小号，可能导致更多安全问题，可使用不支持多开小号的皮肤站。如有能力和需求（难度较高），可自行准备相关资源，在符合相关法律法规的情况下，自行搭建皮肤站。如何搭建？[GitHub - bs-community/blessing-skin-server](https://github.com/bs-community/blessing-skin-server) (请注意，这并不意味着可以使用简幻欢搭建，如发现，封禁简幻欢账号处理）。
>
