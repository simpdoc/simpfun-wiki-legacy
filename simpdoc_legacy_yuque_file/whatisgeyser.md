## Geyser简介
[Geyser](https://geysermc.org/)<font style="color:rgb(28, 30, 33);"> 是允许Minecraft Java版和Minecraft 基岩版在同一服务器畅玩的，支持多种服务端的程序。</font>

<font style="color:rgb(28, 30, 33);">该项目的最终目标是让 Minecraft：Bedrock Edition 用户</font>**<font style="color:rgb(28, 30, 33);">尽可能无缝的</font>**<font style="color:rgb(28, 30, 33);">加入 Minecraft： Java Edition 服务器，</font>

<font style="color:rgb(28, 30, 33);">——也就是某些人所说的互通服的实现。</font>

## <font style="color:rgb(28, 30, 33);">支持的服务端类型</font>
+ <font style="color:rgb(28, 30, 33);">Bukkit系服务端(包括但不限于Spigot、Paper及下游分支等)</font>
+ <font style="color:rgb(28, 30, 33);">BungeeCord、Velocity 代理端</font>
+ <font style="color:rgb(28, 30, 33);">Fabric</font>
+ <font style="color:rgb(28, 30, 33);">NeoForge</font>
+ <font style="color:rgb(28, 30, 33);">ViaProxy</font>
+ **<font style="color:rgb(28, 30, 33);">独立端</font>**

## <font style="color:rgb(28, 30, 33);">它是如何工作的</font>
<font style="color:rgb(28, 30, 33);">Geyser 充当位于 Bedrock 客户端和 Java 服务器之间的转换器</font>

<font style="color:rgb(28, 30, 33);">它从 Bedrock 客户端获取数据，并将其转换为 Java 服务器可以理解的格式，反之亦然</font>

<font style="color:rgb(28, 30, 33);">Geyser 适用于任何现代 Minecraft 版本,可以作为插件安装或作为独立程序运行</font>

## <font style="color:rgb(28, 30, 33);">随时随地加入</font>
<font style="color:rgb(28, 30, 33);">Geyser 可以从 Windows 10/11、iOS、Android 甚至控制台上的 Bedrock 客户端加入，更多信息</font>[在这里](https://wiki.geysermc.org/geyser/using-geyser-with-consoles/)<font style="color:rgb(28, 30, 33);">?</font>

<font style="color:rgb(28, 30, 33);">也可以用作自己的独立代理来加入任何 Minecraft 服务器！</font>



:::warning
[geyser](https://geysermc.org/)往往只支持最新的Minecraft游戏版本

也建议使用最新的版本

:::
