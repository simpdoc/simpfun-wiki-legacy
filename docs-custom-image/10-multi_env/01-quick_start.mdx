#
:::warning[提示]
镜像基于 Debian 12 ( 最新 LTS ) 开发
:::

AIO v1 镜像包括以下所有内容：
    - `Go` ( 1.24.2 )
    - `Java` ( ZuluJDK 8，11，16，17，19，21 )
    - `Net` ( 6，8，9 )
    - `Node` ( 22.14.0 ) + Yarn + PNPM
    - `Python` ( 3.9.22，3.10.17，3.12.10，3.13.3 )
    - `SteamCMD` ( Latest )
    - `Wine` ( 10 ) + Mono

### Java
:::info[信息]
基于 Mise 部署

:::

版本：ZuluJDK 8 11 16 17 19 21

详见【环境调用方法】与【调用信息对应表】

:::tip[成功]
现可使用 root 用户运行。

:::

为保证兼容，我们设定环境变量为旧版本的 `${openjdk+版本}`（已写入镜像内，无需在`start.sh`内写入）。

:::warning[警告]
**MC Java版服务端应该使用哪个版本的Java？**

1.7.10 —— 1.16.5 需要使用 Java 8 ；

1.17 —— 1.20.4 需要使用 Java 17 或更高版本；

1.20.5+ 需要使用 Java 21 或更高版本！

如果你使用的为模组端，那么部分mod可能对Java版本有特定要求。

[如何导入简幻欢没有的Java请点这里查看相关文档。](/mcje/advanced/addownjava)

:::

# 我在什么时候需要使用自定义镜像？
在基础镜像和第三方镜像均不能满足需求时，可使用自定义镜像。

:::danger[警告]

在简幻欢，我们专注于提供游戏服务器的支持和服务。请注意，我们的平台仅适用于游戏服务器的搭建，若发现在此建立其他服务（如网站，网盘等），**简幻欢将关闭您的服务器并永久封禁您的账户**。

:::
