# 【LeviLamina】手动安装 LeviLamina

:::warning[警告]
因存在无法攻克的技术问题，本文档暂时搁置，以下内容仅供参考，无法作为安装教程。

:::

:::info[信息]
在简幻欢中， `AIO` 镜像支持使用 `lip` 安装LeviLamina。

:::

## 操作步骤

### 安装镜像
> [新建服务器](/web/create) ，选择 `基础镜像` -> `自定义-需有开服经验` -> `AIO` ，或 [重装服务器](/web/features/instance/reinstall) ，选择 `基础镜像` -> `自定义-需有开服经验` -> `AIO` 。
>

### 修改启动参数
> 将 `start.sh` 中的启动命令修改为 `bash` ，正确的内容如图所示：
>
> ![说明图片](/img/pages/mcbe/xveib7sepf8z6qup-1.png)
>

### 运行安装命令
> 启动服务器，根据 [快速开始 - LeviLamina Docs](https://lamina.levimc.org/zh/quickstart/) 中的安装命令（无需切换目录，一般安装命令为 `lipinstallgithub.com/LiteLDev/LeviLamina` ，如有变动请以官方教程为准），运行安装命令，安装完成界面如图所示：
>
> ![说明图片](/img/pages/mcbe/xveib7sepf8z6qup-2.png)
>
