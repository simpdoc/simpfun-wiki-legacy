# 【MCJE】如何添加 mod

:::warning[警告]

此教程**仅适用**于以下服务端：

Forge，NeoForge，Fabric，Arclight，Catserver，SpongeForge

:::

:::warning[警告]

请注意mod是否有前置，是forge还是fabric，是否适用于你的版本。

部分mod不支持也不应该添加到服务端，您应先检查是否支持，可前往 [MC百科|最大的Minecraft中文MOD百科](https://mcmod.cn) 查询。

fabric服务端默认**不存在**fabric-api，你应该从下方链接获取并放到 mods 文件夹：

[点击下载](https://modrinth.com/mod/fabric-api/)

:::
