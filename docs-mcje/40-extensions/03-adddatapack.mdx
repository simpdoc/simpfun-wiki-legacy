# 【MCJE】如何添加数据包

:::warning[警告]
⚠ **提示**

1. 数据包仅在1.13及更高的版本可用。
2. 每个数据包兼容的版本都不一样，加载数据包前请确认其兼容的版本！

:::

## 步骤
1. 进入实例，点击`文件`；
2. 转到`/world/datapacks`文件夹(此处的`world`为你在`server.properties`内的`level-name`设置的值)；
3. 将你需要加载的数据包(.zip文件)放到此处；
4. 在游戏内(需要[op权限](/mcje/common_operations/op))或者控制台处输入`/reload`，等待数据包载入即可。

## 额外事项
:::info[提示]
+ 与插件/mod不同，服务器是可以热重载数据包的。也就是说，在**装载数据包的时候你可以不关闭服务端**。
+ Bukkit系服务端中，只需要在`world/datapacks`文件夹内放入数据包即可，`world_nether`与`world_the_end`文件夹不用管。

:::
