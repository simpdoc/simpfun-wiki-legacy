# 【MCJE】更改 motd 和图标来美化服务器

:::info[提示]
你可以更改服务器的motd设置和图标，从而使服务器在服务器列表里更好看一些。

![说明图片](/img/pages/mcje/setmotd-1.png)
:::

## 服务器描述

### 更改服务器描述（motd）
也可见于[server.properties文档](/mcje/server_properties)；

在`server.properties`文件中，有值`motd`，SFE4中默认为SFE4 SERVER。如下：

```properties
motd=SFE4 SERVER
```

将motd=后的内容改为自己想要的描述即可。

如果只是单纯更改文字，则描述会显示为灰色。

1.19.4及以下的版本需要将非英文字符(例如中文)转码为Unicode编码（[在线工具地址](https://www.metools.info/code/c39.html)/[离线工具下载](https://wwd.lanzouo.com/iE2Jh26kpvxi)）。

1.20及以上版本的server.properties已经默认使用UTF-8编码读取/写入，因此无需再进行转码__。

### 使用插件来丰富描述
原版的motd设置中只有灰色，那hypixel和上图里那些**花里胡哨的字体**都是怎么来的？

实际上，有针对motd的插件/mod可以帮助您丰富motd设置。

#### MiniMOTD
MiniMOTD 是一个基本的 MOTD 插件，兼容 Minecraft 1.8 以上的版本（还支持 BungeeCord、Sponge、Velocity、Fabric、Forge、NeoForge 等）。

插件可以增加RGB颜色、添加渐变色等。

使用教程可以参照[MC百科上的这篇帖子](https://www.mcmod.cn/post/3950.html)。

:::info[下载地址]

所有插件端/代理端：[MiniMOTD - Minecraft Plugin](https://modrinth.com/plugin/minimotd/versions?l=sponge&l=velocity&l=folia&l=paper&l=waterfall)

Fabric(1.16+)/NeoForge(1.21.1+)：[MiniMOTD - Minecraft Plugin](https://modrinth.com/plugin/minimotd/versions?l=neoforge&l=fabric)

Forge(1.12.2 ~ 1.20.1)/NeoForge(1.20.6 ~ 1.21.4)：[MOD下载 - MiniMOTD Reforged - MC百科](https://www.mcmod.cn/download/7670.html)

:::

#### ColorMOTD
与此相似的插件还有ColorMOTD。教程参见[这篇专栏](https://www.bilibili.com/read/cv9428815/)。

## 服务器图标

### 为服务器添加好看的图标
很明显，让服务器更好看不仅仅只有抛弃白字，还有自定义图标对吧？

你需要准备一个`.png`后缀的图片文件，分辨率为16x16、32x32或64x64。

将图片命名为`server-icon.png`然后上传到服务器根目录，重启即可应用图标！
