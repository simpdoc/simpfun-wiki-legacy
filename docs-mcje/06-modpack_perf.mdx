# 【MCJE】整合包性能需求参考

:::warning[警告]
***该性能参考为不跑图，不进行大量导致卡服操作等非正常游玩情况下的结果，仅供参考。***
仅需 S.A.M+.L ，即可满足大部分热门整合包需求。
:::


## 推荐优化方案（也是以下整合包配置方案）

server.properties:
- `allow-flight=true`
- `max-tick-time=-1`
- `enforce-secure-profile=false`
- `view-distance=8`

  
/world/serverconfig/forge-server.toml：   
（仅 forge，防止实体异常导致崩溃，影响正常游玩，可能导致丢失部分内容） 
- `removeErroringEntities = true`
- `removeErroringBlockEntities = true`
