## 图文教程（服务端专用安装器版）

### 第一步：安装服务端

前往[Fabric官网](https://fabricmc.net/use/installer/)，在下载页面选择红框内的`Minecraft Server`：

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-2.png)

在跳转到的新页面中选择`MC版本`，`Fabric Loader版本`(Fabric Loader默认选择最新版即可)后，点击下载：

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-3.png)

下载完成后将文件上传至实例文件的根目录。   
打开根目录下的`start.sh`，将启动服务器的命令改为下面的命令后保存(不要删除start.sh自带的东西，echo那一行除外)：

```shell
${openjdk21} -server -Xms1024M -Xmx${maxmem}M -jar <服务端文件名>.jar -nogui
```

:::tip[提示]
`<服务端文件名>`换成你下载到的安装器的文件名，例如`fabric-server-mc.1.21.3-loader.0.16.9-launcher.1.0.1`：

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-4.png)
:::

此时的启动命令应如下图所示：

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-5.png)

:::info[关于各项参数的说明]
`{openjdk17}`：调用变量`openjdk17`。这个变量在上面的默认内容里被定义过了。

+ _注意：_
+ _1.14——1.16.5需要Java8（部分版本的mod可能需要Java 11或Java 16）_
+ _1.17——1.20.4需要Java 17或更高版本_
+ _1.20.5——1.21.11需要Java 21或更高版本_
+ _26.1+需要Java 25或更高版本_

`-server`：用于指示 JVM（Java虚拟机）在服务器环境中运行。这个参数实际上是一个优化标记，它告诉JVM使用更适合长时间运行和高性能的配置。

`-Xms1024M`：服务器运行最小内存为1024Mib。你可以更改`1024M`这个值：如果觉得最小运存太大可以改为`512M`或其他值，只要数字部分是4的倍数；如果强迫症不想使用M作为单位，可以改为`1G`，效果同样。

`-Xmx${maxmem}M`：服务器运行最大内存为maxmxm M。maxmxm是上文定义的变量，为服务器最大物理内存-1000（单位M）。如果不想要这个~~烦人的~~变量名可以把`${maxmem}`整个改成数字，让它变得和`Xmx`这一项看起来一样。**注：**`**Xmx**`**与**`**Xms**`**均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**

`-jar`：告诉Java你要启动jar文件。此项不要更改或删除。

`fabric-server-mc.1.21.3-loader.0.16.9-launcher.1.0.1.jar`：此处替换为你下载到的文件的名字。

`-nogui`：不启用MC服务端自带的一个GUI窗口，在面板服/命令行环境运行服务端时不能删！
:::

保存后回到终端，启动服务器，服务端将会自动下载文件，请耐心等待一会。   
当服务端正确下载完成后，服务器将直接启动，此时，控制台上很可能会显示以下信息，之后服务器将停止运行：

```verilog
[20:35:55] [main/WARN]: Failed to load eula.txt
[20:35:55] [main/INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

### 第二步：同意EULA

转到`文件`页面，打开根目录下的`eula.txt`。

```properties
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Sat Nov 18 21:32:42 CST 2023
eula=false
```

将其中的`false`改为`true`。

:::danger[警告]
将eula中的`false`改为`true`即视为你已阅读并同意[《MINECRAFT 最终用户许可协议(EULA)》](https://www.minecraft.net/zh-hans/eula)!
此外，若您需安装整合包，应在修改EULA后 **不启动服务器，**在内容全部正确导入后，再启动。   
:::

回到`终端`界面，点击右上角的`启动`，等待服务器首次运行。   
看到类似以下的提示即可关闭服务器：

```plain
[20:44:03] [Server thread/INFO]: Done (7.900s)! For help, type "help"
```

### 第三步：配置服务器

再次进入`文件`页面，打开根目录下的`server.properties`。   
简幻欢在上一步启动服务端生成文件时已自动修改`server-ip`为`0.0.0.0`，`server-port`为你实例分配到的端口号，因此可以不用管这两个。   
如果你或者你的朋友没有正版账户，请把`online-mode`的值由`true`改为`false`。请注意，这样做会显著增加你的服务器遭受恶意攻击的风险！   
如何保护你的服务器：[【MCJE】使用正确的登录方式保护服务器](/mcje/auth_type)   
**更多关于服务器设置的配置请查看这篇文档：**[【MCJE】server.properties详解](/mcje/server_properties)   
需要更换存档请参考这篇文档：[【MCJE】导入存档到服务端](/mcje/world_io/upload_worlds)    
Mod文件放入`/mods`文件夹。   
现在你已经配置好服务端了，去愉快地玩游戏吧！

## 图文教程（通用安装器版）

### 第一步：安装服务端

前往[Fabric官网](https://fabricmc.net/use/installer/)，点击`Download universal jar`下载通用安装器。

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-6.png)

下载完成后将其上传至实例文件的根目录。   
打开根目录下的`start.sh`，在文件内添加一行下面的命令后保存(不要删除start.sh自带的东西，echo那一行除外)：

```shell
${openjdk17} -jar <安装器文件名>.jar server -mcversion <MC版本号> -downloadMinecraft
```

:::tip[提示]
`<安装器文件名>`换成你下载到的安装器的文件名(不要尖括号)   
`<版本号>`换成你需要的服务端版本，例如`1.19.3`(不要尖括号)
:::

例如，当安装器文件名为`fabric-installer-1.0.1`，需要的服务端版本为`1.20.1`时，命令应如下图所示(第14行)：

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-7.png)

保存后回到`终端`页面，启动服务器，此时安装器将会自动安装服务端核心并下载依赖文件。   
完成后服务器将会停止运行。

### 第二步：调整启动命令

打开根目录下的 `start.sh` (在Windows镜像下为`start.cmd`)，**先把第一步添加的那行命令删除**，然后再添加一行类似下面的命令后保存(不要删除文件里原本的东西，除了最下面那行echo)：

```shell
${openjdk17} -server -Xms1024M -Xmx${maxmem}M -jar fabric-server-launch.jar -nogui
```

:::info[关于各项参数的说明]
`{openjdk17}`：调用变量`openjdk17`。这个变量在上面的默认内容里被定义过了。

+ _注意：_
+ _1.14——1.16.5 需要 Java8_
+ _1.17.——1.20.4 需要 Java17 或更高版本_
+ _1.20.5——1.21.11 需要 Java21 或更高版本_
+ *26.1+ 需要 Java25 或更高版本*

`-server`：用于指示 JVM（Java虚拟机）在服务器环境中运行。这个参数实际上是一个优化标记，它告诉JVM使用更适合长时间运行和高性能的配置。

`-Xms1024M`：服务器运行最小内存为1024Mib。你可以更改`1024M`这个值：如果觉得最小运存太大可以改为`512M`或其他值，只要数字部分是4的倍数；如果强迫症不想使用M作为单位，可以改为`1G`，效果同样。

`-Xmx${maxmem}M`：服务器运行最大内存为maxmxm M。maxmxm是上文定义的变量，为服务器最大物理内存-1000（单位M）。如果不想要这个~~烦人的~~变量名可以把`${maxmem}`整个改成数字，让它变得和`Xmx`这一项看起来一样。**注：**`**Xmx**`**与**`**Xms**`**均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**

`-jar`：告诉Java你要启动jar文件。此项不要更改或删除。

`fabric-server-launch.jar`：Fabric构建器生成的启动Fabric服务端的文件，此项不要更改。

`-nogui`：不启用MC服务端自带的一个GUI窗口，在面板服/命令行环境运行服务端时不能删！
:::

调整完的启动命令应类似下图所示：

![说明图片](/img/pages/mcje/customer-mcje-fabric-server-8.png)

此时你可以删除 Fabric 安装器了。

### 第三步：同意EULA

启动服务器，稍微等待一会后控制台会出现类似如下的提示并关闭服务器：

```verilog
[21:32:42] [main/INFO] [minecraft/Main]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

转到`文件`页面，打开根目录下的`eula.txt`。

```properties
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Sat Nov 18 21:32:42 CST 2023

```

将其中的`false`改为`true`。

:::danger[警告]
将eula中的`false`改为`true`即视为你已阅读并同意[《MINECRAFT 最终用户许可协议(EULA)》](https://www.minecraft.net/zh-hans/eula)!
:::

回到`终端`界面，点击右上角的`启动`，等待服务器生成文件。   
看到类似以下的提示即可关闭服务端：

```verilog
[21:33:52 INFO]: Done (38.223s)! For help, type "help"
```
