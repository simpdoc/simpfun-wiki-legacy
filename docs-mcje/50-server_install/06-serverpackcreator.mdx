# 【MCJE】安装由 ServerPackCreator 生成的整合包

## 什么是由SPC生成的整合包？
ServerPackCreator 是一款专为简化 Minecraft 服务器包（Modpack）创建流程而设计的自动化工具，由此工具打包出来的服务端整合包即为SPC生成的服务端。

### 快速判断整合包服务端是否由SPC生成
检查服务端压缩包内是否有下图红框圈出的文件（尤其是有无`variables.txt`），如果都有则为SPC打包的服务端。

或者查看压缩包附带的信息（如下图所示的右边明确写明了`Server pack made with SPC 7.2.4`）。

![说明图片](/img/pages/mcje/customer-mcje-serverpackcreator-1.png)

标题旁的小三角符号可以展开对应的段落！

## 使用AIO镜像安装
1. 新建/重装实例为“自定义——AIO镜像”

![说明图片](/img/pages/mcje/customer-mcje-serverpackcreator-2.png)

2. 上传服务端整合包到实例根目录，然后解压缩
3. 解压缩完成后打开`variables.txt`，找到`RECOMMENDED_JAVA_VERSION`这行，如下图中①处，记下等号后的数字
4. 然后将`JAVA`等号后的内容(如下图②处)修改为`${openjdk*}`，***为上方数字**

![说明图片](/img/pages/mcje/customer-mcje-serverpackcreator-3.png)

修改完成后应如下所示：

```bash
RECOMMENDED_JAVA_VERSION=17
JAVA_ARGS="-Xmx5G -Xms5G"
JAVA="${openjdk17}"
```

:::info[提示]

AIO镜像默认仅包含Java 8/11/16/17/19/21，如果整合包需要的Java版本不是这6个，请自行下载后[使用环境变量调用](/web/advanced/custom_env)！

:::

5. 回到终端，启动服务器，此时SPC启动脚本应开始下载服务端，需要你同意EULA，输入“I agree”后回车。

![说明图片](/img/pages/mcje/customer-mcje-serverpackcreator-4.png)

6. 等待服务端下载完成（此过程可能会非常长，请耐心等待）。
7. 安装完成后根据需要修改`server.properties`。

:::info[提示]

如果出现服务端下载失败的情况可以多重试几次，或者在本地下载完成后[上传至实例](/mcje/serverpack_install)！

:::

### 附加教程：更改jvm参数
打开`variables.txt`，找到如下图所示的这一行来修改JVM参数。

![说明图片](/img/pages/mcje/customer-mcje-serverpackcreator-5.png)

例如，可以把Xmx参数改为`-Xmx11G`(建议更改JVM最大内存为"`实例内存-1G`"，如实例有12G内存，则Xmx设置为11G)，然后添加一个`-server`参数，如下所示：

```bash
JAVA_ARGS="-server -Xmx11G -Xms5G"
```
