# 【MCJE】在简幻欢使用自定义的 Java

:::info[信息]
ℹ ****众所周知，简幻欢提供了一些常用的java供用户使用，但总有人**有一些特殊需求**。那么，本文将教你如何在简幻欢使用自定义的java。

:::

## 上传，解压java
+ 从[zulu](https://www.azul.com/downloads/)或[华为镜像源](https://repo.huaweicloud.com/java/jdk/)等Java下载地址下载需要使用的java **压缩包**

:::warning[警告]
⚠ **提示**

+ 务必选择正确的java，不要选择arm和32位的java，请选择amd64或x86_64。
+ 简幻欢中的docker镜像均为Linux系统，请使用适用于Linux系统的Java，而不是Windows！

:::

![说明图片](/img/pages/mcje/addownjava-1.png)

+ [上传](https://simpdoc.top/docs/upload)并解压下载好的java ![说明图片](/img/pages/mcje/addownjava-5.png)![说明图片](/img/pages/mcje/addownjava-2.png)

:::info[信息]
ℹ **提示**

如果你获取到的压缩包为`.tar.gz`格式的，可参考这篇文档：[无需排队就能进行的解压/压缩操作](/web/advanced/zip) 来进行解压。

:::

## 获取解压后的java路径，编辑启动参数
+ 根据图示，寻找到解压后的java文件。如图中当前java文件在 `/zulu21.30.15ca-jre21.0.1-linux_x64/bin` 中，则你的java路径为 `/zulu21.30.15ca-jre21.0.1-linux_x64/bin/java`。 ![说明图片](/img/pages/mcje/addownjava-6.png) 编辑你的 start.sh ，修改启动参数，如图示： ![说明图片](/img/pages/mcje/addownjava-3.png)

**一切准备妥当后，启动服务器即完成操作！** ![说明图片](/img/pages/mcje/addownjava-4.png)
