# 【MCJE】在简幻欢使用自定义的 Java

众所周知，简幻欢提供了一些常用的 java 供用户使用，但总有人**有一些特殊需求**。那么，本文将教你如何在简幻欢使用自定义的 java。

## 上传，解压java

1. 从[zulu](https://www.azul.com/downloads/)或[华为镜像源](https://repo.huaweicloud.com/java/jdk/)等Java下载地址下载需要使用的java **压缩包**

:::warning[提示]
+ 务必选择正确的 java，不要选择 arm 和 32 位的java，请选择 amd64 或 x86_64。
+ 简幻欢中的 docker 镜像均为 Linux 系统，请使用适用于 Linux 系统的 Java，而不是 Windows！
:::

![说明图片](/img/pages/mcje/addownjava-1.png)

2. [上传](https://simpdoc.top/docs/upload)并解压下载好的 java

![说明图片](/img/pages/mcje/addownjava-5.png)

![说明图片](/img/pages/mcje/addownjava-2.png)

## 获取解压后的java路径，编辑启动参数

3. 根据图示，寻找到解压后的java文件。如图中当前java文件在 `/zulu21.30.15ca-jre21.0.1-linux_x64/bin` 中，则你的java路径为 `/zulu21.30.15ca-jre21.0.1-linux_x64/bin/java`。 

![说明图片](/img/pages/mcje/addownjava-6.png) 

4. 编辑你的 `start.sh` ，修改启动参数，如图示：

![说明图片](/img/pages/mcje/addownjava-3.png)

5. **一切准备妥当后，启动服务器即完成操作！**
