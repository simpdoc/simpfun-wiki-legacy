# 【MCJE】关闭正版验证

:::warning[警告]
我们并不提倡使用非正版进行游玩，如无必要，请勿关闭正版验证！

:::

_注：似乎SFE4中的预设默认关闭正版验证（在线模式）来着_

想和朋友联机但是没有正版？只需在服务器内关闭正版验证即可轻松联机！

## 正版和非正版的区别？
| | **正版** | **非正版** |
| --- | --- | --- |
| **皮肤** | 只需在官网设置好，即可使用！ | 需使用其它办法实现皮肤显示，否则为默认皮肤 |
| **服务器连接** | 可以游玩正版服务器，如hyp(由于正版验证API原因，位于国内的正版服务器可能会出现无法连接的问题) | 只能游玩离线服，但由于无需验证服务器验证，连接相对流畅 |

## 修改配置文件来关闭验证
:::warning[警告]
⚠ **提示**

`server.properties`不支持热重载，请在关闭服务器的情况下对其进行修改。

:::

进入服务器文件管理，在根目录找到`server.properties`文件并打开;

![说明图片](/img/pages/mcje/mcje-online-mode-1.png)

在其中找到这一行:

```properties
online-mode=true
```

将`true`改为`false`即可关闭正版验证。

:::info[提示]
**支持正版！**

### 如果条件允许，我们建议您通过微软商店购买正版！

:::
