# 【学习交流】加入 QQ 交流群

您可以加入 QQ 交流群/频道交流简幻欢相关问题，需要**绑定**才可以进群/发言，违反群规可能会被封禁，请遵守规则。

## 绑定教程

+ 打开[简幻欢官网→控制台](https://simpfun.cn/console)，选择"其它"页面。
+ 在"绑定QQ号"处填写你的QQ号后，点击右边的"保存"图标即可。

![简幻欢控制台绑定 QQ 号页面说明图片](/img/pages/web/joinqqgroup-1.png)

## 群聊开放时间

:::warning[请注意]

全部官方群的群聊开放时间为**每天 07:00-24:00**。其余时间群聊关闭，无法发言，请勿在此时段内等待回复。

:::

## 如何加群

请先完整阅读目标群的群规；充分阅读、了解后自然了解群聊入口。

| 类型 | 定位 | 群规 |
| --- | --- | --- |
| 综合交流群 | 日常交流、经验分享与有限宣传 | [综合交流群群规](/web/joinqqgroup/general_chat) |
| 第三方镜像交流群 | 第三方镜像的申请、代装、反馈与催更 | [第三方镜像交流群群规](/web/joinqqgroup/third_party) |
| 新界面测试群 | 新界面的测试与问题反馈 | [新界面测试群群规](/web/joinqqgroup/ui_testing) |
| 疑难解答群 | 专门解决项目相关问题，不闲聊 | [疑难解答群群规](/web/joinqqgroup/support) |

## 如何辨识官方群

:::warning[请注意]

只有各群规页面中公布的群号为简幻欢官方交流群，任何其余个人、组织、公司等无权以简幻欢官方名义创建任何群聊。

:::

另外，官方群与管理员不会以任何理由私聊索要您的账号密码、微信支付验证码，也不会要求您向个人账户转账。遇到此类情况，请先核对群号，并通过官方渠道向项目负责人核实。

## 群规更新与解释

群规的最终解释权归简幻欢所有，简幻欢保留随时修改或更新群规的权利，以适应群的发展和变化。

各群群规为正式文本，并在页面顶部标注修订日期。群公告与本文可能存在版本差异，以修订日期较新的版本为准。
